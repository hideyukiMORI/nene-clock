## 3. 🔑 例外区画が 3 つある（最重要）

「ここだけ許す」場所が 3 つある。**除外は必ずそのモジュールの `build.gradle.kts` の差分として見える。**

| 区画 | 外している署名 | 許されること | なぜ |
| --- | --- | --- | --- |
| `:adapters:system-time` | `determinism.txt` | 現在時刻・既定ゾーンを読む | ARC-007 の唯一の窓口 |
| `:adapters:font-catalog` | `platform.txt` | `GraphicsEnvironment` を読む | 利用可能な書体の唯一の窓口。**時計は読めないまま** |
| `:app` | `process-control.txt` ＋ bundled `jdk-system-out` | 端末出力・`System.exit` | 窓が出る前の唯一の伝達経路（[ADR 0005](../adr/0005-composition-root-owns-the-terminal.md)） |

さらに**可変状態の隔離区画が 2 つ**ある（ARC-005）。

| 区画 | 何が可変か |
| --- | --- |
| `:ui:swing` の Swing 部品の内部 | 部品の描画状態 |
| `:core:application` の `SettingsHandler` | 「現在の設定」を指す参照 1 つだけ（[ADR 0004](../adr/0004-settings-state-owner.md)） |

🔴 **4 つ目の区画を作らない。** 必要になったら ADR で問い直す。
ArchUnit の規則には区画の名前が直接書いてあるので、2 つ目を作ると検査が落ちる。

## 4. 地雷（初日に実際に踏んだ／踏みかけた）

1. **`.gitignore` の `build/` は、パッケージ名の `build` セグメントにも一致する。**
   検査エンジンのソースが丸ごとコミットから抜けていた。パターンはアンカーしてある（`/build/` `/*/build/`）。
   **パッケージ名に `build` を使わない**（`...neneclock.gradle.conformance` に改名済み）
2. **included build（`build-logic`）のタスクは `check` から自動では呼ばれない。**
   ルートの `build.gradle.kts` で明示的に `dependsOn` している。外すとテストが静かに走らなくなる
3. **precompiled Kotlin script plugin は同じソースセットの Java クラスを解決できない。**
   Gradle プラグインは Java の `Plugin<Project>` として書く（`ConformancePlugin`）
4. **`record` の正準コンストラクタは公開度を下げられない。**
   不変条件を持つ値型は `final class` ＋ 非公開コンストラクタ ＋ 唯一のファクトリ（JAV-007）
5. **`switch` に `default` を書いた瞬間に網羅性検査が死ぬ。** CNF-003 が拒否する
6. **Checkstyle の `MissingSwitchDefault` は採用していない。** JAV-002 と正面から矛盾するため（不採用の理由を明記）
7. **NullAway が効いているので「null を渡すテスト」は書けない。**
   書けないこと自体をコメントで残してある（`UserSettingsTest`）
8. **テストの引数は 4 個まで**（JAV-012）。値の組は名前付きの型で渡す。初日に 1 回引っかかった

## 8. 作業の型（初日に 12 PR 回して機能した）

1. **Issue を先に立てる。**「問題と根拠 / 意図する結果 / 影響する規則 / 受け入れ条件 / 検証の計画 / やらないこと」
2. 設計そのものを変えるなら**先に** ADR と規範文書。実装と同じ変更で入れる
3. ブランチ → 最小の実装 → テスト → `./gradlew check`
4. **コミットごとに `git worktree add` で切り出して `check` を回す**（手元だけ緑の状態を潰す）
5. PR 本文は定型（`docs/DEVELOPMENT_WORKFLOW.md` 第 7 節）。**却下した選択肢と残るリスクを必ず書く**
6. CI 緑を確認してから squash merge → `main` を同期 → ブランチを消す

⚠️ ゲートが落ちたら**コードを直す**。閾値・除外・重大度を触るのは ADR 相当の判断（QLT-010）。
⚠️ `planned` を `active` と書き換えない。実装してから書き換える。
