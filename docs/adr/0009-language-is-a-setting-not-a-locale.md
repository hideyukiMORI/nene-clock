# ADR 0009 — 言語は設定であって、実行環境のロケールではない

- 状態: 受理
- 日付: 2026-09-04
- Issue: #42
- 影響する規則: ARC-007 / ARC-009 / FR-006 / FR-042 / FR-048 / JAV-002

## 文脈

施主要件により、画面の文言を日本語と英語で切り替えられるようにする。

Java には標準の仕組みがある（`ResourceBundle` ＋ `Locale`）。しかしその既定の入口
（`ResourceBundle.getBundle(name)`）は**既定ロケール＝実行環境の状態**を読む。
このリポジトリは、現在時刻も書体一覧も「環境から読まない」と決めてきた（ARC-007 / ADR 0006）。
言語だけ環境から読むのは、その判断と噛み合わない。

もう 1 つの問題は書体である。時計の書体は同梱して環境依存を消したのに、
**UI の書体だけ実行環境の既定に任せていた**。日本語の描画品質が環境まかせになっていた。

## 決定

**言語は保存される設定にする。UI の書体も同梱し、言語から決まる従属的な値とする。**

- `Language`（JAPANESE / ENGLISH）を設定項目に加える。保存形式は v5 へ上がる
- 実行環境のロケールを読まない。読む経路をそもそも作らない
- 文言は `UiText` 列挙に集める。**1 つの定数が両方の言語を持つ**
- UI の書体は `InterfaceTypeface` として同梱し、`Language` から引く。利用者は直接選ばない
- 時計の表示（`HH:mm:ss` / `yyyy-MM-dd`）は言語に影響されない（FR-006 のまま）

### 文言を「1 定数 = 両言語」にした理由

言語ごとにファイルを分けると、**片方だけ足してもう片方を忘れることができる**。
1 つの定数が両方を持つ形なら、定数を足した時点で両方書かないとコンパイルが通らない。
翻訳の抜けを「レビューで気をつけること」にしない（ADR 0001）。

### 書体の選定

| 用途 | 採用 | 大きさ | 既定インスタンス |
| --- | --- | --- | --- |
| 日本語 | Zen Kaku Gothic New | 2.4 MB | Regular |
| English | Arimo（Arial とメトリック互換） | 0.5 MB | Regular |

🔴 **Noto Sans JP は採れなかった。** 上流（google/fonts）には可変版しか無く、
**9.6 MB あって既定インスタンスが Thin** である。Java 21 には可変フォントの軸を選ぶ API が無い
（ADR 0006 / #36 で同じ理由で 4 書体を差し替えた）。

## 強制

- **active**: 文言がその言語の書体で**描けること**を `:ui:swing` のテストが見る
  （`Font#canDisplayUpTo`）。両方の言語が空でないことも見る
- **active**: UI 書体も同梱書体の検査（存在・SHA-256・既定が Regular）に含める
- **active**: v4 からの移行を `:adapters:preferences` のテストが見る
- **planned**: 3 言語目を足したときに書体も足したかの検査。
  いまは言語が 2 つしか無く、`Language` に書体を持たせてあるので足し忘れようがない

## 結果

得られるもの:

- 海外の利用者が使える
- 日本語の描画品質が環境に依存しなくなった
- 翻訳の抜けがコンパイルで止まる

失うもの:

- **同梱物が 2.9 MB 増えた**（合計 約 10 MB）
- 3 言語目を足すと、文言だけでなく書体も増える。中国語・韓国語なら数 MB 単位で増える
- 実行環境が日本語なのに英語で起動する場合がある（**それが決定である**）

## 却下した選択肢

| 選択肢 | 却下の理由 |
| --- | --- |
| `ResourceBundle` ＋ 既定ロケール | 実行環境の状態を読む経路が生まれる。ARC-007 / ADR 0006 と噛み合わない |
| 初回起動だけロケールを見て既定を決める | 「環境を読む経路」は 1 回でも作れば残る。読んだ値が保存値と食い違ったときの規則も必要になる |
| 言語ごとに文言ファイルを分ける | 片方だけ足して忘れられる。翻訳の抜けが機械で止まらない |
| UI 書体を実行環境に任せる | 時計の書体を同梱した理由がそのまま当てはまる。日本語の品質が環境まかせになる |
| Noto Sans JP を同梱する | 可変版しか無く、9.6 MB で既定が Thin。Java 21 では Regular を選べない |
| 言語の選択肢を英語 UI でも「日本語」と表示する | Arimo に日本語の字形が無く、豆腐（□□□）になる。**実機で踏んだ** |
