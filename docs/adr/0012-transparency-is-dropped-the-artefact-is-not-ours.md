# ADR 0012 — 透明度をやめる。ちらつきはアプリの外にあった

- 状態: 受理
- 日付: 2026-09-04
- Issue: #49 / #55 / #57 / #58
- 影響する規則: FR-002 / FR-040 / FR-042 / FR-044 / FR-046 / FR-047
- 関係: [ADR 0011](0011-transparency-is-asked-for-not-assumed.md) を**置き換える**

## 文脈

施主要件で色に透明度を入れた（#49）。直後から「毎秒ちらつく」という報告が続いた。

原因を 4 回誤診し、そのたびに直しを入れて確かめてもらった。

| 回 | 見立て | 入れた直し | 結果 |
| --- | --- | --- | --- |
| 1 | 部分再描画と `AlphaComposite.Src` の噛み合わせ | 毎秒、面全体を描き直す | **悪化**（窓全体がちらつくようになった） |
| 2 | Swing が下を消している | 面が「不透明」と名乗る | **悪化**（壊れた矩形が残った。裏画面がアルファを持たないため） |
| 3 | 透明を経由する 2 手描き | 角の外側だけ透明にする | 変わらず |
| 4 | ルートペインが白で塗っている | ルートまで不透明・裏画面を降ろす | 変わらず |

## 決め手になった実測

推測をやめ、**自分で観測できる状態**を作った。刻みを 200ms から 30ms へ上げ（毎秒 33 回の描き直し）、
窓の画素を 40 枚撮った。

```text
明るい（白い）画素を含むフレーム: 0 / 40
支配色: (60, 25, 38) = 36% の半透明が正しく合成された色
壊れた不透明画素: 0
```

🔑 **アプリが描いている絵は、最初から一度も壊れていなかった。**
`import` が読むのは窓自身の画素であり、そこに白は一度も現れない。
つまり白は**窓を画面へ合成する層**（WSLg / Weston / Windows RAIL）で入っている。

ちらつく範囲が「文字の矩形」「クロームの矩形」「窓全体」と、そのとき更新を通知した範囲に
ぴったり一致していたことも、合成側の挙動として筋が通る。

## 決定

**透明度をやめる。** 色は RGB の 3 成分に戻し、窓は常に不透明にする。

- `RgbaColor` → `RgbColor` へ戻す（名前が中身と食い違ったままにしない）
- 色ピッカーから不透明度のつまみを外す
- 窓は `setUndecorated` ＋ `setShape` の切り抜き（M0.2 の形）へ戻る
- 保存形式は **v7**。v6 が持っていた透明度の値は読み捨てる

## なぜ「残して記録する」を採らなかったか

**施主の環境で見た目が壊れる設定は、設定として嘘になる。**
「使えるが、使うと汚くなる」つまみを画面に置くのは、
押しても何も起きないボタンを置くのと同じ種類の誤りである（ADR 0010）。

## 強制

- **active**: 色は 3 成分。透明度を持つ経路がコードに存在しない
- **planned**: 「別の環境なら使えるか」の確認。この判断は **WSLg での実測に依存**している

## 結果

得られるもの:

- ちらつきが無くなる（不透明な窓では一度も観測されなかった）
- 描き方が 1 通りに戻る（半透明のときと、そうでないときの分岐が消える）

失うもの:

- **背景を透かせない。** 机の上のガラスのような見え方はできない
- 4 日ぶんの往復と、施主の目を 5 回借りた。**測れる状態を先に作らなかったことの代償**である

## 🔑 この一件から残す教訓

1. **直して悪化したら、それは診断である。** 仮説どおりなら軽くなるはずのものが重くなったら、
   直し方ではなく見立てを疑う
2. **観測できないものを直そうとしない。** 4 回の誤診はすべて「見えないまま直した」結果である。
   刻みを上げて撮れる状態にしたのは 5 回目で、そこで 10 分で決着した
3. **「アプリの中が壊れている」と決めてかからない。** 壊れていないことを示せれば、
   探す場所が外へ移る

## 却下した選択肢

| 選択肢 | 却下の理由 |
| --- | --- |
| 透明度を残し、制限として記録する | 施主の環境で見た目が壊れる設定は、設定として嘘になる |
| Java2D のパイプラインを変える（`xrender` / `opengl`） | 窓の合成は JVM の外。パイプラインを変えても合成側の挙動は変わらない |
| 透明度を「上級者向け」として隠す | 隠して残すのは、直さないことの言い換えである |
| ネイティブの Linux で試してから決める | この製品が動くのは施主の WSLg である。そこで壊れるなら、そこで判断する |
