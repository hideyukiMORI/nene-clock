# ADR 0011 — 半透明は「頼んで、断られたら諦める」

- 状態: 受理
- 日付: 2026-09-04
- Issue: #49
- 影響する規則: FR-044 / FR-046 / FR-047 / ARC-007 / ARC-009
- 関係: [ADR 0007](0007-one-colour-type-two-roles.md) の「透明度は持たない」を改める

## 文脈

施主要件により、文字色と背景色に透明度を持たせる。
FR-044 は「透明度（アルファ）は持たない」と明記し、透過ウィンドウは
SPECIFICATION 第 5 節「将来の候補（着手しない）」に置いていたので、**判断を覆す変更**である。

技術的な問題は 1 つだけある。**半透明で描けるかどうかは環境依存**であり、
その可否を読む標準の手段は `GraphicsEnvironment` である。しかしこのアプリは
`GraphicsEnvironment` を読まないと決めている（[ADR 0006](0006-typefaces-are-bundled-not-discovered.md)）。

実測（この環境）:

```text
PERPIXEL_TRANSPARENT  = true
TRANSLUCENT           = false     ← 窓全体の一様な不透明度は使えない
PERPIXEL_TRANSLUCENT  = true      ← 画素ごとの半透明は使える
```

## 決定

**可否を読まない。頼んでみて、断られたら不透明で描く。**

- 窓の生成時に `setBackground(透明)` を一度だけ試す。
  受け入れられたら半透明が使える。`UnsupportedOperationException` /
  `IllegalComponentStateException` が返ったら使えない
- 使える場合: 地も角丸も `ClockPanel` が描く。**縁が滑らかになる**
- 使えない場合: 地は不透明で描き、角丸は `setShape` の切り抜きで作る（従来どおり）
- 透明度は `RgbaColor` の 4 つ目の成分。既定は不透明。保存形式は v6 へ上がる
- **コントラストの警告は不透明として計算する。** 透けた先に何があるかは読みようがない

### 型の名前を変えた

`RgbColor` は RGB の 3 成分を意味する名前だった。透明度を持つ以上、その名前は嘘になる。
`RgbaColor` へ改名した。**名前が中身と食い違ったまま増築しない。**

### 生成経路

検証を通る経路は `of(red, green, blue, alpha)` ただ 1 本のまま。
`opaque(red, green, blue)` はそこへ委譲する短縮であって、第 2 の検証経路ではない（JAV-007）。

## 強制

- **active**: 透明度の範囲・`withAlpha` が他の成分を保つこと・v5 からの移行で不透明になること
- **active**: 描画の色への変換は `AwtColour` ただ 1 か所。
  透明度を足す前は `new Color(r, g, b)` が 4 か所に散っていた。散ったままだと必ず落とす箇所が出る
- **planned**: 「半透明が使えない環境で不透明に落ちる」ことの検査。
  可否は環境が決めるので、この環境では常に片方しか通らない

## 結果

得られるもの:

- 背景を透かせる。時計が机の上のガラスのように置ける
- 半透明が使える環境では、角丸が `setShape` の硬い切り抜きより滑らかになる

失うもの:

- 描き方が 2 通りになった（半透明のときと、そうでないとき）。
  **どちらか一方しかこの環境では試せない**
- 背景を透かすと、コントラストの警告が当てにならなくなる（不透明として計算しているため）

## 却下した選択肢

| 選択肢 | 却下の理由 |
| --- | --- |
| `GraphicsEnvironment` で可否を読む | 環境を読む経路を作らないと決めている（ADR 0006）。読めたところで、頼んで断られる可能性は残る |
| 窓全体の一様な不透明度（`TRANSLUCENT`）を使う | **この環境で使えない**（実測）。文字だけ不透明に保つこともできない |
| 透明度を持つ型を別に作る | 同じ「0..255」の規則が 2 か所に写る（ADR 0007 と同じ理由） |
| `RgbColor` の名前のまま透明度を足す | 名前が中身と食い違う。増築のたびに嘘が積もる |
| 透けた先の色を推定してコントラストを出す | 窓の下にあるものは読めない。推定した数字は嘘になる |
